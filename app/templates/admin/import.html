FORMATS PRIS EN CHARGE

Import unitaire ou de masse

Import multiple : sélectionnez plusieurs DOCX, PDF ou fichiers Markdown dans le sélecteur.

Archive ZIP : regroupez jusqu'à 100 documents dans une archive. Les sous-dossiers sont parcourus. Les fichiers pris en charge sont DOCX, PDF, Markdown, CSV et JSON. Les fichiers cachés et formats inconnus sont ignorés.

Word (.docx) : conversion en article éditable. Les titres, paragraphes, listes, tableaux, liens et images compatibles sont repris. Le résultat est créé en brouillon.

Markdown (.md / .markdown) : prise en charge des titres, listes, tableaux, liens, citations, blocs de code et mise en forme courante. Le résultat est créé en brouillon par défaut.

PDF : création d'une fiche avec visionneuse intégrée. Le PDF reste stocké hors du répertoire statique.

CSV / JSON : chaque ligne / objet représente un article. Champs reconnus : title, slug, summary, content_html, content_markdown, category, tags, status, featured.

En mode « mettre à jour », seuls les brouillons existants sont remplacés. Une fiche déjà publiée n'est jamais écrasée par l'import : un nouvel article est créé avec un slug suffixé.

Pour le Markdown, un front matter facultatif peut définir title, slug, summary, category, tags, status et featured.
